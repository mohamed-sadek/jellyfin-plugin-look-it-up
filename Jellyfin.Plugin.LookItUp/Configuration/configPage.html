Look it up

Precomputes timed Wikipedia annotations from subtitles, then shows short popups during playback. Prefer Prepare library over scanning while watching.

Prepare library

Scans movies/episodes offline, extracts text subtitles, looks up names, and stores JSON for playback. You can also run this from Dashboard → Scheduled Tasks → Look it up — prepare library.

Use this for testing a single episode/movie. Do not use Prepare library for that.
Status will appear here.

AI extraction

During prepare, local name candidates are ranked from subtitles, then the top N are each sent in one OpenAI-compatible request. The model must verify the candidate is a real name/reference before returning a short summary. If Groq is flaky, switch to OpenAI or OpenRouter below (same flow).

Changing provider fills a recommended model and base URL. You still need that provider’s API key.
Leave blank to keep the existing key. Only paste a new key when replacing it. Groq: console.groq.com/keys · OpenAI: platform.openai.com/api-keys · OpenRouter: openrouter.ai/keys
Groq: openai/gpt-oss-20b. OpenAI: gpt-4o-mini. OpenRouter: openai/gpt-4o-mini.
Usually filled by the provider preset. Ollama default: http://127.0.0.1:11434/v1.
How many top local candidates get one verify+define request each (start with 5).

Web client overlay

Load the overlay with JavaScript Injector (or File Transformation). Paste JavaScript — not an HTML <script> tag (that breaks public.js with Unexpected token '<'): 

(function () {
  var s = document.createElement('script');
  s.src = '/LookItUp/script.js?v=1.2.22';
  s.async = true;
  document.head.appendChild(s);
})();
Hard-refresh after saving. Console should show overlay ready 1.2.20.0 and popup settings applied.
