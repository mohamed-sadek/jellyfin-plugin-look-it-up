Look it up

Precomputes timed Wikipedia annotations from subtitles, then shows short popups during playback. Prefer Prepare library over scanning while watching.

Prepare library

Scans movies/episodes offline, extracts text subtitles, looks up names, and stores JSON for playback. You can also run this from Dashboard → Scheduled Tasks → Look it up — prepare library.

Use this for testing a single episode/movie. Do not use Prepare library for that.
Status will appear here.

Lookup settings

Language code for Wikipedia summaries (e.g. en, fr, de).
Comma-separated language codes (e.g. en,eng).

AI extraction

During prepare, local name candidates are collected from subtitles, then one OpenAI-compatible chat call resolves them in context (e.g. Jon Voight the actor, not a surname etymology). Prefer Groq llama-3.1-8b-instant for free-tier speed.

Groq (recommended), OpenAI, OpenRouter, Ollama, or None (legacy Wikipedia).
Stored in Jellyfin plugin config. Leave blank to keep the existing key when saving. Groq: console.groq.com/keys
Recommended Groq: llama-3.1-8b-instant (fast). Optional: llama-3.3-70b-versatile. OpenAI: gpt-4o-mini.
Groq: https://api.groq.com/openai/v1. OpenAI: https://api.openai.com/v1.
