Look it up

Precomputes timed Wikipedia annotations from subtitles, then shows short popups during playback. Prefer Prepare library over scanning while watching.

Prepare library

Scans movies/episodes offline, extracts text subtitles, looks up names, and stores JSON for playback. You can also run this from Dashboard → Scheduled Tasks → Look it up — prepare library.
