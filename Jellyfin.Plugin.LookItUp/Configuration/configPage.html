Look it up

Builds a *.lookitup.json cache incrementally while you watch. Popups are optional — turn them off to collect data without on-screen distractions.

When off, incremental prepare still runs and sidecar JSON is still written.

Incremental prepare

Smaller chunks at start / after seek so opening-minute references finish in time (default 60000).
How far ahead to prepare once caught up (default 300000 = 5 minutes).

Subtitles

Comma-separated codes (e.g. en,eng).
When no external or embedded text subtitles are found, Look it up automatically tries OpenSubtitles. Credentials are imported from the Jellyfin OpenSubtitles plugin when the fields below are empty.
opensubtitles.com account (not .org). Leave blank to use Jellyfin OpenSubtitles plugin login.
Leave blank to keep the saved password / Jellyfin plugin password.
Leave blank to use the same shared API key as Jellyfin's OpenSubtitles plugin.

AI verification

Leave blank to keep the saved key. Gemini: Google AI Studio key.
HTTP requests per minute (one request per name, with a short delay between names).

Popup appearance

Only applies when popups are enabled.

Base size at ~1280px-wide screens. When scale-with-screen is on, larger/smaller viewports adjust from this.
Popup card width. Text wraps inside this; default 320.
Larger on TVs / wide monitors, smaller on phones and tablets. Width scales only lightly so cards stay compact.
CSS color for popup title and body (hex, rgb/rgba, or named color).
CSS color for the popup outline (hex, rgb/rgba, or named color).

Web client

Paste into JavaScript Injector (not an HTML <script> tag):

(function () {
  var s = document.createElement('script');
  s.src = '/LookItUp/script.js?v=1.2.54';
  s.async = true;
  document.head.appendChild(s);
})();
