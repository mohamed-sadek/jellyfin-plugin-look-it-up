Look it up

Scans external subtitles for names (places, people, organizations), looks them up on Wikipedia, and shows a short popup at the moment they are mentioned during playback.

Language code for Wikipedia summaries (e.g. en, fr, de).
Comma-separated language codes used when choosing a subtitle file (e.g. en,eng).

Web client overlay

Jellyfin server plugins cannot inject playback UI by themselves. Load the overlay script in your web client (Custom JavaScript plugin, userscript, or a small web client patch): 

<script src="/LookItUp/script.js"></script>
